# Handoffs

Notes left by an agent after substantial work, for whoever continues.

- Naming: `YYYY-MM-DD-short-topic.md`.
- Use `TEMPLATE.md`.
- The final section is **Recommended Immediate Next Consideration**: one item, not a backlog.
- Handoffs are informal and sit at the bottom of the source-of-truth hierarchy. If a handoff contradicts code or an experiment record, the code or record wins.
