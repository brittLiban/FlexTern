# REV-2026-11-07: Phase 1.2 design, advisor review of the first draft

Status: advice from an independent advisor pass over the first draft of `experiments/EXP-0013-phase1-2-design.md`; not an accepted decision. The design file was revised the same day; this records what was raised and what changed.

| # | point raised | disposition |
|---|---|---|
| 1 (blocking) | The map+memory versus timer comparison mixed memory with prediction: C1 had no memory of its own press, so a C2 win could mean only "remembering a press helps", and a reviewer could call C1 deliberately weakened. | Added **C1+** (C1 plus one persistent "I entered S" bit, no countdown, no DELTA/W). It is in the non-predictive set used by V2 and GO-1. Twin alpha is relabelled an event-memory twin (resolved by C1+); beta and gamma are timing twins (need C2). Information matrix and evidence ladder updated (E1a event memory, E1b timing prediction). |
| 2 (blocking) | The 1.25x deadline multiplier was justified by its expected effect on blind retry loops, which is choosing a parameter for a predicted outcome; the v2-A "waiting fits in the budget" claim was asserted, not guaranteed. | Deadline is v1's inherited 1.5x rule; the sentence explaining 1.25x was removed. The deciding metric is deadline-free regret censored at `T_CAP = ceil(2 x p95 oracle)`, independent of `T_D`; a 1.0x-2.0x sweep is reported. v2-A uses `T_D,A = max(1.5 p95, p95 + P)` as an explicit requirement. Also found while fixing this: v1's base environment hard-codes an 80-step timeout, so a `T_CAP` above 80 needs v2's own timeout (noted as an implementation requirement with a test). |
| 3 | C2's behaviour in v2-A was unspecified although V3/V4 score it there. | Specified: C2 gets `P` and the open length and extrapolates the phase from the last gate transition it saw; with none seen it behaves like C1. |
| 4 | V5 was vacuous (every twin that survives rejection passes). | Preregistered minimum yields on DEV2 (alpha >= 100 per condition, beta/gamma >= 60 in LA_OCC); stated that beta/gamma twins will mostly come from LA_OCC; failing the yield means the condition is untestable, not that the minimum is relaxed. The numbers are TARGETs (no yield has been measured). |
| 5 | The literature differentiator "separates memory from prediction" probably overclaims. | Searched POPGym, Memory Maze / R2I and the Ni et al. memory-versus-credit-assignment paper. Differentiator reworded: not new by itself; the possibly new combination is a same-information hand-coded predictor bar plus observation dropout plus perception-cost accounting (INFERRED from abstracts; coverage limits stated). |
| 6 | Process: persist this review, add founder decisions to `OPEN_QUESTIONS.md`, push the branch, lead the report with the unmerged closeout. | Done: this file; Q-029 to Q-032; branch pushed (never `main`); the final report opens with the merge status. |
