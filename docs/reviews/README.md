# Reviews

Structured critiques from independent reviewer and advisor agents (Fable and others).

- Naming: `REV-YYYY-MM-DD-topic.md`.
- Use `TEMPLATE.md`.
- Reviewers are expected to challenge the project: question assumptions, methodology, baselines, and architecture. Agreement is not the goal.
- A review is advice. It changes nothing by itself. If the founder accepts a durable change, it is recorded as an ADR in `../decisions/`.
- Reviewers do not rewrite architectural decisions unless explicitly tasked to implement.
