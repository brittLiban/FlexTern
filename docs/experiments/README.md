# Experiments

FlexTern is a research project; experiments are first-class artifacts.

- Naming: `EXP-XXXX-short-description.md`, four-digit zero-padded, sequential.
- Use `TEMPLATE.md`.
- Every number in `../BENCHMARKS.md` must trace to a record here and a commit hash.
- Negative results are recorded with the same care as positive ones.
- A failed experiment is never rewritten to look successful. Mark it Abandoned or Complete with its actual outcome.
- Raw outputs go in `/results/`, referenced from the record.
